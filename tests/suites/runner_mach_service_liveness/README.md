# runner_mach_service_liveness

Regression guard for the BYOXPC `xpc_timeout` launch bug.

## What it proves

The built `PWRunner` executable, launched **directly** with
`--mach-service <name>` — the shape the generated BYOXPC LaunchAgent uses
(`ProgramArguments = [PWRunner, --mach-service, <service>]`) — binds
`NSXPCListener(machServiceName:)` and stays alive in its run loop, instead of
aborting under `xpc_main`.

A host that calls `NSXPCListener.service()` for this launch aborts immediately
(`"An XPC Service cannot be run directly."`, SIGABRT) because the process was
not started as an XPCService bundle. That is exactly what made
`policy-witness runner verify` return `normalized_outcome: xpc_timeout` for a
`--kind byoxpc` runner: the host crashed on launch before answering XPC.

The listener selection itself is pinned hermetically in `runner_unit`
(`pwListenerConfig` table, `ListenerConfigTests.swift`); this suite pins the
end product — the actual shipped binary does not abort on the BYOXPC launch.

## How it runs

- Launches `…/PWRunner.xpc/Contents/MacOS/PWRunner --mach-service com.pw.test.liveness.<pid>`
  in the background. It is **not** bootstrapped under launchd (no `MachServices`
  receive right), so it never services a real connection here — the suite only
  asserts the process does not abort.
- After a short beat, reads the process state via `ps -o stat=`. A zombie (`Z`,
  the process exited) or a vanished PID → the runner aborted → **fail**. Any live
  state → the runner bound a mach-service listener and is in its run loop → **pass**.
- The process is killed and reaped before the suite returns.

`kill -0` is intentionally **not** used for the liveness check: an aborted child
becomes a zombie until reaped, and `kill -0` succeeds on zombies, so it cannot
tell "alive" from "exited".

## Skips when

`dist/PolicyWitness.app` is missing or unbuilt (the `PWRunner` executable is not
present). A built tree must pass; there is no other expected skip.

## Artifacts

- `artifacts/pwrunner.stderr.log` — the runner's stderr for the launch (captures
  the libxpc abort message on a regression).
