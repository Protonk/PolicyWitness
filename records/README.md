# Problem records

This directory contains prose records of user or development problems:
observations, reproduction steps, investigations, and their evidence. These
records provide background for associated plans; they are not active plans or
the repository's current behavior contract.

`archive/` holds completed investigations, dated surveys and their retained
evidence. Its README describes the material and its availability. Deferred
questions and records supporting current plans remain outside the archive.

[AGENTS.md](AGENTS.md) governs links to records and evidence provenance.
