## K-249-1 · C:249 · example

**Pass.** examples-reply
**Claim.** "a foreign live peer behind a matching registry entry receives no specimen submission"
**Mechanism.** Three comparisons take part, in three processes. The controller checks the registry record; the client and the host each check the other's self-reported contract string during reservation; the specimen is sent only after the client has admitted a `granted` control reply.
1. Controller (Rust), registry gate: for an external runner, `resolve_external_target` calls `runner_manager::require_current_contract(&record.contract)`, which requires the stored string to be non-empty, not `"unbound"` and equal to `BUILD_CONTRACT`. This compares the registry record's string only, not the bundle or the running service. "A matching registry entry" means this passes. For the built-in runner there is no registry record and this step does not apply (`runner_select.rs:430-438`).
2. Controller launches `pw-runner-client` with the held request on stdin (not re-read here). The client (Swift, `PWRunnerClientSession`) opens an XPC connection and sends a reservation request (`reserveRunner`), which carries `contract`, an attempt id and a lease, and no specimen fields (per the struct name `PWRunnerReservationRequest` and the Pass 4 trace; the struct was not opened).
3. Host (Swift, `PWRunnerService.reserveRunner`): bounds the request size; decodes only `{contract}`; if its own `PWBuildContext.contract` is `"unbound"` or the request's contract differs, replies with control status `unsupported_protocol` and grants no reservation. Its control replies carry the host's own `contract` (default value of `PWRunnerControlReply.contract`).
4. Client, `reservationReply` -> `decodeControl`: bounds the reply size; decodes only `{contract}`; if its own contract is `"unbound"` or the reply's contract differs, throws `ControlFailure.unsupported` before decoding the rest. The catch block ends the attempt as `protocol_error` with reason `unsupported_protocol`, sets `acquisition_stop = "protocol_error"`, calls `complete("protocol_error")` and returns. `retry()` is not called on this branch.
5. The only call to `connection.submit(request, reservation:)` is at line 252, after an admitted reply with status `granted`, a valid token and lease, a deadline check, `phase = .submitted` and `capture.submission = {state: "invoked"}`. On the refusal branch `capture.submission` keeps its initial state.
6. Controller: the capture's terminal event `protocol_error` maps to outcome `"xpc_protocol_error"` (`runner_client.rs:636`); `admit_reply` returns `Refused`, exit 1; `runner_result` null; `fallback_eligible` is false (terminal is not `xpc_error`), so no fallback compile.
7. Paths by peer behavior: (a) a foreign host running this code refuses at step 3 and the client refuses at step 4, since the host's reply carries the host's contract; (b) a peer that answers with some other well-formed control reply carrying a foreign contract is refused at step 4 alone; (c) a peer that does not implement `reserveRunner` produces a connection failure, handled by `connectionFailed` as `transport_error` followed by `retry()` on a new connection while still acquiring, up to the attempt limit or deadline, with no submission (INFERRED from lines 192-204; not exercised in anything read); (d) a peer that reports the client's contract string and grants receives the submission: the identity compared is the peer's self-report.
8. The host-side and client-side comparisons are separate hand-written Swift code in the same package (`PWRunnerService.swift`, `PWRunnerClientSession.swift`); the registry comparison is hand-written Rust.
**Who acts, and what a consumer observes.** The client (`pw-runner-client`) decides not to submit; a foreign host running this code independently grants no reservation. A consumer sees exit status 1, `result.normalized_outcome == "xpc_protocol_error"`, `data.runner_client.submission == "not_invoked"`, `data.runner_client.transport.terminal == "protocol_error"`, `data.runner_client.transport.error.reason == "unsupported_protocol"`, and `data.runner_result == null`.
