## K-29-1 · C:29-30 · machinery

**Pass.** identity-stamps
**Claim.** "The generator hashes canonical shape goldens and each delimited normative region across reachable annotated release tags."
**Mechanism.** `surface_hash(root, row, tag)`: takes the text between `<!-- BEGIN CONTRACT <id> -->` and `<!-- END CONTRACT <id> -->` in the row's `definition` file (exactly one ordered pair required), collapses whitespace runs, appends the same for each `file#region` in `definitions`, parses each golden as JSON, and hashes `json.dumps([definition, goldens], sort_keys=True, separators=(',',':'))` with SHA-256. With a tag, each input is read by `git show <tag>:<path>`. `release_tags`: empty unless `root` is its own Git top level; otherwise annotated tags matching `vN.N.N`, ordered along `git rev-list --reverse --topo-order HEAD`. `stamps`: walks those tags, skipping any whose tree lacks the manifest; a surface takes the tag's name when it first appears or its hash differs from the previous state, else keeps its stamp; then compares the working tree with the last state (row 27).
**Who acts.** `docs/generate_contract_stamps.py` — stated in the sentence: yes
**Compared with what.** A surface's hash at one tag against its hash at the preceding tag, then against the working tree. "canonical" is sorted-key compact JSON for goldens and whitespace-collapsed text for regions — stated in the sentence: partly
**Boundary.** Regeneration, `--check` with history, release preflight — stated in the sentence: no
**Consequence.** A changed hash changes the "Last changed" cell; a missing or duplicated region marker raises "expected one ordered definition region" — stated in the sentence: no
**Sources.** `docs/generate_contract_stamps.py` : `surface_hash` (174-189), `release_tags` (192-204), `stamps` (207-232)
**Checks.** `build_contracts.py` : `test_pending_release_reproduces_after_tagging_and_tracks_removal` (334-361) — test — default — temp repository; a region edit moves `request` only; text outside regions moves none — reaches: yes.
`build_contracts.py` : `test_golden_change_moves_its_surface_and_malformed_region_refuses` (363-377) — control — default — a golden edit moves `profile`; a removed end marker raises — reaches: yes.
`build_contracts.py` : `test_current_tree_has_complete_stamp_derivation` (293-295) — rule — default — the real checkout with its real tags reproduces both tables — reaches: yes.
