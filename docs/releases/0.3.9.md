# PolicyWitness 0.3.9

`policy-witness example extension` prints a runnable specimen with an issuer and two readers. The guide uses it to move a file-read grant from Alice to Bob and check which worker can read a file with known bytes.

The `request.specimen.emit_example` statement covers both bare `example` and the named form. Each prints a complete specimen bound to the emitting build that its ordinary `run` admits. Use `help example` to see the forms. An unknown name or an extra operand exits 2.
