## Experimental controls and the battery

Eight experimental controls move out of the ordinary specimen. Ordinary `run` refuses those request keys. Use `policy-witness test-input run` with these options when reproducing the corresponding experiment:

| Worker controls | Validator controls |
| --- | --- |
| `--worker-timeout-ms`, `--worker-pre-ready-hang-ms`, `--worker-post-apply-hang-ms`, `--worker-post-apply-kill-signal`, `--worker-kill-before-publish-slot` | `--validator-executable-path`, `--validator-io-timeout-ms`, `--validator-total-timeout-ms` |

The two worker-equipment substitutions `worker_executable_path` and `actor_equipment_executable_paths` remain ordinary request controls where their forms allow them. The experimental command carries its controls separately from the held specimen. [CLI surface](../controller/README.md#cli-surface-contract)

| Converted case or control | What the result now means |
| --- | --- |
| Same-group descendant (`4cb2f91b`) | An observed survivor or prior exit can complete the observation. Evidence for the product's own signal account, an independently observed later step effect and verified cleanup are still enforced. Aftermath builds its own fixture. |
| BYOXPC retirement (`47b455f1`, `7b8f1f46`) | The 48-request sequence records host and client outcomes without a reliability threshold. Sequence validity, generation observations and verified owned cleanup remain enforced. |
| Worker-wait pilot (`9bcefb24`, `8a7596b5`) | Timings and counts are observations. Candidate improvement is advisory under a qualified matched comparison. An ordinary run with no compared candidate establishes no improvement. |
| Four inline assertion blocks (`79aa7dde`) | A violated envelope expectation produces a named case failure and retained diagnostic. A harness interruption still has its own accounting. |

Use `case_outcome_counts` and the observation reports to read the whole battery. The legacy pass count excludes the pytest families. The Markdown reader and worker-wait pilot controls joined the existing exec family. In the trace's final default reread they accounted for 66, 232 and 9 items respectively. Packing, archiving, publishing and later prune previews all have paths that verify archived family evidence. Earlier measurements put the pilot's case evidence near 133 MB, including about 115 MB of repeated sources. A sampled estimate put a large family's gzip rereads near half an hour per archive verification. That is a projection, not a timed 0.3.8 release. The accepted plan bounds archive reads and stores identical blobs once per family while preserving per-item observations. Its implementation is separate from the 0.3.8 guide closeout.
