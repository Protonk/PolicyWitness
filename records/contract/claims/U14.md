## K-255-2 · C:255 · example

**Mechanism.** This is an ordering property, and it is implemented differently on the two sides.
Controller: it never checks unknown keys at the request root; the only unknown-key check it has is inside the `runner` object (`parse_runner_selector_value`, lines 174-186), and that runs after the contract gate. So on the CLI path `schema_version` could not produce `unknown_field` from the controller under any ordering; what the gate's position prevents is a selector refusal being reported first, and the request reaching the host.
