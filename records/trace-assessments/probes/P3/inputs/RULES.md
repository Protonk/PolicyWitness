# P3 rules

Each reader is given one owner file and one rule. List every claim the file makes about that rule.

- Rule A: when PolicyWitness automatically compiles the policy with its standalone helper after a run's reply is lost (the fallback compilation), and where that result appears in the run envelope (`data.policy_check`, `data.actor_policy_checks`).
- Rule B: how `cleanup_trigger` is determined, and how it relates to the stop reason and to the termination cause.
- Rule C: what a step's `order: query_first` establishes, and under what conditions a step gets it.
