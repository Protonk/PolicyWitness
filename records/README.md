# Problem records

This directory contains prose records of user or development problems:
observations, reproduction steps, investigations, and their evidence. These
records provide background for associated plans; they are not active plans or
the repository's current behavior contract.

`archive/` holds selected completed investigations and dated surveys.
Its README describes the material and its availability. Keep the evidence
a current reader, investigation or resource recovery still
uses in the checkout. When a tracked investigation has been condensed into
handoffs, its associated plan can identify the complete Git revision and
original paths. Gitignored runs have their own retention rules.

[AGENTS.md](AGENTS.md) governs links to records and evidence provenance.
