# PolicyWitness 0.3.9

`policy-witness example extension` prints a runnable specimen with an issuer and two readers. The guide uses it to move a file-read grant from Alice to Bob and check which worker can read a file with known bytes.

The `request.specimen.emit_example` statement covers both bare `example` and the named form. Each prints a complete specimen bound to the emitting build that its ordinary `run` admits. The `help example` card shows both invocations and their actors, phases, queries, attempts and extension actions. An unknown name or an extra operand exits 2.

`policy-witness help runner` lists the management commands and the selectors for a recorded installation. After `runner remove` exits 0, the card explains when to discard staging and how to inspect and retry retained cleanup.

`policy-witness help run` lists seven request fields used in the extension example under the form `help run <key>`. Copy a field from a capacity refusal to find its rule and release reference. The attempt target, query filter value and extension issue target each have their own entry. For a listed field, the components of `request_failure.path` joined with dots select the same entry. A recognized admission field without an entry points to the release limits inventory. In 0.3.8 any argument after `help run` printed the run card at exit 0. An argument that selects no entry now exits 2 with empty stdout.
