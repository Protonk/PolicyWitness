# D2 documentation apparatus investigation

This is the package owned by docs/CHECKS-BEFORE-CHECK-PLAN.md under the
WORKSET-PLAN amendments. It records document ownership, actual author edit
paths, localized complications and dispositions of supported corrections.
Its consumer is this workset's implementation and acceptance, not a future
CHECK writer. Initial source: `7562d24ac2334122499ea349010fd67211058ac3`.

Artifacts:

- `intake.md`: accepted D1 prerequisite, absorbed evidence, source differences
  and proposal dispositions.
- `inherited/`: the compact D1 facts needed here, preserved with source hashes
  and original commit identities in intake. No new D1 inbound links are added.
- `ownership.md`, `ownership-facts.json`, `capture.py`: reciprocal ownership
  and separate document populations at the fixed source.
- `trace-evidence.json`: 16 historical accepted/rejected/restoration controls,
  receipt identities and 15 selected source-file comparisons; not a current
  whole-checkout passing credit.
- `traces.md`: six representative edit paths, author repair, checkpoints,
  distribution, cross-generator dependencies and failure/recovery boundaries.
- `reconciliation.md`: localized findings, supported correction scope,
  inherited proposal dispositions and pending decisions.
- `implementation.md`: bounded C1–C3 candidate, preserved boundaries and
  selected verification; no final D2 acceptance is implied.
- `verification.md`, `verification-facts.json`: isolated development run at the
  committed candidate, result/receipt identities and limits of that credit.

Ownership, traces, reconciliation and acceptance records are added as those
phases finish. Current-source accounts always name their examined revision;
historical evidence does not become current by copying it. Initial edits are
limited to this package and its associated plan while E2 modifies shared files.
Retirement follows acceptance and disposition within this workset; coordinate
D1 retirement after absorption, and move any still-needed compact material
before retiring D2's plan and records together.
