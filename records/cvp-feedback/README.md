# Session identifiers for Claude feedback

One JSON file per Claude Code session, named for its session identifier. Each
file pairs that identifier with the `req_` request identifiers of the session's
model turns, the client version, the repository state, the human prompt count
and subject, and the observed outcome. The request identifiers are the keys that
correlate a session with Anthropic's platform records; the session identifier is
generated by the local client.

The sessions themselves are prompts and responses, not PolicyWitness evidence.
Their transcripts live in the local Claude Code state directory and are not
retained here; each file records its transcript path.
