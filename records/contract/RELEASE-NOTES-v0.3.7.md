It states accepted inputs, component boundaries, report fields, applicability and consequences across nineteen public surfaces, with source and check support and explicit unresolved items. The contract incorporates commitments previously split between the contract and user guide.

This is the intermediate contract checkpoint. The thirteen existing surface names remain, and six new surfaces give previously distributed commitments explicit ownership. The existing surfaces receive new digests because their public representation and digest framing changed. The accepted specimen grammar, native operations, report values and success classification retain their existing behavior. Each release continues to use its own exact admission identity. The guide receives factual corrections; its substantive workflow revision follows in 0.3.8.
