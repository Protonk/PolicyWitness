## K-12-2 · C:12 · identity

**Mechanism.** `release_bytes_match(root, tag, paths)`: lists the tag's tree with `git ls-tree -rz`; keeps entries that are named files or have a scoped suffix under a scoped directory; returns false if any kept entry is not a blob of mode 100644 or 100755; returns false unless the kept set equals the on-disk scoped path set; then reads each blob with `git cat-file --batch` and compares it with the on-disk file bytes.
