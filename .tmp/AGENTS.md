# Disposable scratch

Everything here except this file may be removed at any time without confirmation.
Preserve `AGENTS.md` when clearing scratch contents. Do not keep the only copy of
source changes, important notes, test evidence, or resource-cleanup ownership
records here. Move durable work to its appropriate repository location.

Use fresh managed directories under `tests/out/runs/` for test evidence. New
tests do not prune other runs; successful release packaging is the automatic
cleanup checkpoint. Do not move results here to evade that policy.

Scratch has no size threshold, scheduled cleanup, or backup requirement.
