# Stage-four guide evidence

This package preserves guide preparation and independent source reviews, the
section/evidence crosswalk, exact integration and repair hashes, the preceding
release's independently checked footprint transcription, and the initial native
partial audit. Reports retain their original preparation/execution status.
The coordinator's stage-four account joins later evidence to those bounded claims.

The initial selection is a failed whole run: 12 of 16 cases passed. Its four
failures were stale shared-prose test targets, an authored reference to a generated
anchor, the new direct-prune exit expectation, and the guide harness's registry
list-envelope expectation. Repair reports retain each cause and scope. The initial
native audit credits only commands reached before its harness assertion failed.
The corrected selection also remains a failed whole run: 12 of 13 cases passed,
with guide_workflows failed. Its summary preserves that result separately. A final independent native audit is added by the
coordinator separately after it exists. These selections are pre-tag checks; the
maintainer checkpoint still precedes v0.3.8 tagging and tagged release acceptance.

The source/staged-guide assertion belongs to each workflow invocation. The compact
summaries preserve its inputs.json claim, hash the retained guide, and retain the
saved version/build identity. They do not join a later checkout or staged file to
an earlier invocation. Source digests identify bytes; each review and execution
receipt supplies its own coverage. Constructed fake-OS/consumer-admission controls
and native command observations retain their separate grades. Stage-two reused
scenarios and their limits are identified in CROSSWALK.md. Extension JSON/scenario
execution does not establish execution of its newly displayed shell wrappers.

JSON reports/manifests and run summaries use deterministic gzip (empty header
filename, zero modification time). Exact copies preserve decoded source bytes.
For run projections, source_sha256 identifies the complete upstream run.json;
decoded_sha256 identifies the compact summary and stored_sha256 its compressed
bytes. Projection summaries preserve all case results/counts, completion, harness
errors, app-integrity state, sleep observations and execution/selection identity.
Embedded catalogs, plans and repeated report bodies remain in the original run.

Original /private/tmp paths are session-local preparation sources. Original
tests/out paths are gitignored raw evidence subject to ordinary retention. This
package carries audits and compact receipts, creates no retention pin, and changes
no cleanup ownership. The associated CONTRACT-STAGING-PLAN.md owns inbound links.
